Company Screener

A small research tool, ported from Paul's World

Filter a set of well-known companies by sector and by size (measured on last reported fiscal year revenue).

⚠️ This screener uses static revenue figures (sourced from SEC filings / investor releases, snapshotted August 2026) — not live data. The original version of this tool also shows live share-price momentum, but that relies on a serverless price-feed API that this site doesn't have (it's a plain static site with no backend), so those columns aren't included here.
